# E-commerce Operations Management

## Project Overview

This project demonstrates an E-commerce Operations Management system developed using Monday.com.

The system was designed to provide visibility and structure across order management, inventory monitoring, supplier coordination and order fulfilment.

The project simulates a practical operational environment where managers need to monitor orders, identify potential delays, prioritise issues and coordinate actions.

## Business Objectives

- Improve visibility of outstanding orders.
- Monitor inventory availability.
- Track order fulfilment progress.
- Identify high-priority operational issues.
- Improve supplier and delivery coordination.
- Provide a centralised operational reporting view.

## Tools & Technologies

- Monday.com
- Kanban workflow management
- Dashboard and reporting
- Operational KPI monitoring
- GitHub documentation

## Project Features

### 1. Operations Management Table

Centralised order tracking with:

- Order identification
- Priority classification
- Inventory status
- Order dates
- Order fulfilment status
- Supplier information
- Order values
- Customer and store information
- Expected delivery dates
- Required operational actions

### 2. Kanban Workflow

A visual workflow for monitoring orders according to priority.

The board includes:

- Critical
- High
- Medium
- Low

Each card displays important operational information to support decision-making and follow-up.

### 3. Dashboard & Reporting

An operational dashboard providing an overview of:

- Total tasks
- Orders in progress
- Stuck orders
- Completed orders
- Overall completion progress

### 4. Operations Timeline

A timeline view was explored for operational scheduling. Advanced Gantt functionality was unavailable under the free plan.

## Business Value

This project demonstrates how operational management tools can support:

- Better order visibility
- Proactive inventory monitoring
- Improved prioritisation
- More structured fulfilment processes
- Clearer accountability
- Faster identification of operational bottlenecks

## Project Scope

This is a demonstration project using simulated operational data. It is not connected to a live e-commerce platform or production order management system.
